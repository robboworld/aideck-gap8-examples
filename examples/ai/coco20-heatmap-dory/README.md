# Детектор COCO20 с heatmap-головой DORY

Пример AI-deck содержит 20-классовый детектор объектов для grayscale-кадров
Himax. В прошивке используются квантизованные NEMO/DORY-операции, CPX-вывод,
передача результата и Wi-Fi-подготовка кадра.

## Контракт модели

Вход — `uint8` формы `1x1x160x160`. Нативный кадр `324x244` сохраняет пропорции
при letterbox-предобработке. Heatmap-сетка имеет размер `20x20`; на каждую
ячейку приходятся 20 class-logit и четыре значения bbox. Выход до декодирования
имеет форму `24x20x20` и целочисленный формат.

## Пересборка и проверка

Исходники в `generated/` создаются пайплайном из каталога `tinyml_demo`:

```bash
./scripts/docker_generate_detector_dory.sh
./scripts/package_aideck_runtime.sh
```

Скрипты проверяют квантизацию, копируют только исходники runtime и payload,
устанавливают совместимый с FreeRTOS DMA-адаптер и записывают SHA-256
метаданные. Сгенерированные каталоги не следует редактировать вручную.

## Сборка платы

```bash
make clean all CORE=8 platform=board
make flash CORE=8 platform=board
```

Прошивка публикует через CPX декодированные классы, confidence, координаты
bbox и счётчик циклов. Визуализация на ПК описана в
`tinyml_demo/docs/live_detection_contract.md`.

## Ограничения

Проверка GVSOC и компиляция не гарантируют качество на живой камере. Метрики
нужно считать на фиксированном COCO20 test-разбиении, а после этого отдельно
проверять latency, память L1/L2, OTA-прошивку и физический AI-deck.
